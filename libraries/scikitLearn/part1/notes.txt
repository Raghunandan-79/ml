    What actually is Machine Learning ?
    ->  Machine Learning is when a machine or a computer learns from past data 
        it is known as machine learning. Here computer learns from past data or 
        experiences. For e.g: Youtube Recommendations, Instagram Reels Feed, 
        NetFlix Recommending Movies, Bank Fraud Notifications, etc.
    
    Artificial Intelligence VS Machine Learning VS Deep Learning
    ->  1. AI is the outer layer which helps machine to act smartly.
        2. Machine Learning is the Layer 2 it is a part of AI. It helps machine to
           learn from data automatically.
        3. Deep Learning is layer 3 and it is powerful brain which will 
           be present inside out machine. Automated cars are part of Deep Learning.
           DL requires a big data.
        
        For Example:
        AI -> Entire School
        ML -> classes
        DL -> Student

    Scikit Learn -> It is a powerful library which can be used for training models.

    Types of Machine Learning
    ->  1. Supervised Learning: Ideal for tasks with labeled data where the 
                                desired output is known. Here you get both input and 
                                output
        2. Unsupervised Learning: Suitable for identifying patterns in unlabeled
                                  data without explicit guidance. Here you will get
                                  only input
        3. Reinforcement Learning: Best for training agents to make decisions through
                                   interaction with an environment. It is basically
                                   actions + reward.

        3. Model
        4. Training 
        5. Testing
        6. Prediction
